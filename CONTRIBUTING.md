# Coding rules

1. **Variable names use camelCase.** Example: `studentName`, not `student_name`.
2. **Indent with 4 spaces.** Example: the code inside `if { ... }` is moved 4 spaces to the right.
3. **Use meaningful names.** Example: `scoreSum`, not `s1`. One-letter names are allowed only for loop counters or when the task gives them (a, b).
4. **Write a short comment above every loop and every non-obvious calculation.** Example: `// Read 5 scores for one student`.
5. **One statement per line and lines shorter than 100 characters.** Example: write `a++;` and `b++;` on two lines.
