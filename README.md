# Grade Calculator

A console program in C++ that calculates the average score and the grade of students. It is made for teachers who want a fast way to check results of a group.

## Requirements
- The program shall read the name of a student and exactly 5 scores.
- The program shall reject any score that is not a whole number from 0 to 100 and ask again.
- The program shall calculate the average and show it with one decimal place.
- The program shall show the grade for each student.
- The program shall accept several students until "end" is typed, then show the number of students and the class average.

## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | below 60 |

## How to run
1. Open https://www.onlinegdb.com and choose C++.
2. Paste the code from main.cpp and click Run.
